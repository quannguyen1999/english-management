## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Talk with AI – Realtime TTS Setup

The "Talk with AI" feature uses a WebSocket for realtime text-to-speech. You must run the Python TTS server from the reference folder **before** using it:

```bash
cd refenrence
pip install -r requirements.txt
uvicorn server:app --port 8000 --reload
```

Keep this server running. The frontend connects to `ws://localhost:8000/tts`. To use a different URL, set `NEXT_PUBLIC_TTS_WS_URL` in `.env.local`.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
